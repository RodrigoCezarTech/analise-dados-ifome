# Análise de Dados — iFome Delivery

## Sobre o projeto

Projeto de análise exploratória de dados de uma empresa fictícia de delivery, desenvolvido com Python para identificar indicadores operacionais, padrões de pedidos e oportunidades de melhoria.

## Tecnologias utilizadas

- Python
- Pandas
- Matplotlib
- Google Colab
- Git e GitHub

## Etapas do projeto

1. Limpeza dos dados, tratamento de duplicatas e identificação de valores ausentes.
2. Cálculo de indicadores de desempenho (KPIs).
3. Análise de pedidos, faturamento, cancelamentos e avaliações.
4. Visualização de dados e identificação de insights de negócio.

## Principais resultados

- 320 pedidos após remoção de duplicatas.
- 284 pedidos entregues.
- Ticket médio dos pedidos entregues: aproximadamente R$ 80,18.
- Tempo médio de entrega: 45,6 minutos.
- Taxa geral de cancelamento: 11,25%.
- Categoria com maior faturamento em pedidos entregues: Lanches.
- Correlação entre tempo de entrega e avaliação: 0,013.

## Conclusão

A análise permitiu identificar diferenças operacionais entre bairros e categorias de produtos, além de explorar a relação entre o tempo de entrega e a satisfação dos clientes.

Os resultados podem apoiar investigações e decisões voltadas à melhoria da operação.

## Como executar

1. Baixe os arquivos `analise_ifome.ipynb` e `pedidos.csv`.
2. Abra o notebook no Google Colab.
3. Envie o arquivo `pedidos.csv` para o ambiente de execução.
4. Execute as células na ordem apresentada.
